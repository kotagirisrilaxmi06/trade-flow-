TradeFlow ERP + CRM Operations Portal

Comprehensive Technical Blueprint, System Architecture, API Contract & Operational Specifications

1. Executive Summary & Business Context

TradeFlow Operations Portal is a production-ready full-stack Mini ERP and CRM system built for wholesale and distribution enterprises. The platform integrates sales management, customer CRM tracking, real-time inventory guardrails, purchase order fulfillment, and financial invoicing into an executive dark-mode dashboard.

  • Sales & CRM: Customer lead lifecycle management, classification (Retail, Wholesale, Distributor), and timestamped follow-up interaction history.
  • Warehouse & Inventory: Real-time stock tracking, minimum stock alert triggers, and immutable stock movement logging (IN/OUT).
  • Sales Challans Engine: Automatic numbering (CH-YYYYMMDD-XXXX), immutable product snapshotting, and atomic stock validation preventing negative stock.
  • Accounts & Finance: Supplier purchase order tracking and customer billing invoice creation.

3. System Architecture & Tech Stack

The system utilizes a Unified Monorepo Architecture deployed on Vercel's serverless infrastructure with an SSL-encrypted PostgreSQL backend.

  • Frontend: React 18, TypeScript, Vite, CSS with glassmorphism aesthetics, brand logo, and smooth micro-animations.
  • Serverless API: Node.js, TypeScript, Express.js deployed to Vercel Serverless Functions at /api/index.ts.
  • Database Layer: Neon Cloud PostgreSQL (PostgreSQL 18.4) with Node pg.Pool connection pooling.
